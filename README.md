
# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search, and delete notes. Users can assign each note to a Personal, Work, or Study category. The application also saves notes in the browser using localStorage, so notes remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work, or Study
- Display notes as cards
- Delete individual notes
- Search notes
- Case-insensitive searching
- Validate empty notes
- Limit notes to 200 characters
- Display the total number of notes
- Save notes using localStorage
- Load notes after refreshing the page
- Responsive design for smaller screens
- Clear all notes with confirmation

## How to Run Locally

1. Clone the repository:

    ```bash
   git clone https://github.com/DenisNjoroge121/quicknotes-app.git
    ```

2. Open the project folder:

   ```bash
   cd quicknotes-app
   ```

3. Open `index.html` in a web browser.

No server or additional dependencies are required.
